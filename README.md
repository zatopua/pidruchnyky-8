# Підручники 8 клас — сторінка зліва, тези справа

Сайт: https://zatopua.github.io/pidruchnyky-8/

Оберіть предмет — відкриється підручник, а поруч короткі тези саме тієї сторінки, яку ви читаєте.
Тези згенеровано автоматично (Claude) з картинки й тексту кожної сторінки та перевірено скриптом
(числа в тезах звірено з текстом сторінки); можливі неточності — орієнтуйтеся на сам підручник.

Підручники — електронні версії видань МОН України; авторські права належать авторам і видавництвам.
Сайт — навчальний проєкт; у разі заперечень правовласника матеріали буде прибрано.

Код і конвеєр збірки — у приватному робочому репозиторії (projects/pidruchnyky-8).
